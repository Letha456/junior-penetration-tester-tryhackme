**How to use it:**

2. Open your terminal.
3. Then type this in your terminal:

   ```
   dirb [website name eg https://example.com]
   ```

4. And it should return its findings.

## Defensive Security

This is also known as the blue team. Its main concern is mainly prevention and detection. You are detecting and preventing any threats that your system could face.

This is where SOC analysts come into the picture, which stands for Security Operations Centre. They are a team of professionals that continuously monitor a company's network and system operations to detect and prevent any malicious threats. They make use of tools like SIEM.

The next field I was taught in DS was digital forensics. They are professionals who basically analyse and preserve the digital evidence that could help in regards to an attack, for example, a breach. They use things such as logs, etc.

The next is incident response, which is basically the management of incidents that occur after an attack, how you approach them, the mitigations and preventions for next time, and you document this entire process.
